# Python Syllabus Project

A small full-stack project for practicing the Python topics from Unit 3 and Unit 4.

## Used
- HTML, CSS and JavaScript
- Python and Flask
- Algorithms in `backend/algorithms.py`

## Run
1. Open this folder in a terminal.
2. Install Flask with `py -m pip install -r requirements.txt`
3. Start the project with `py backend\app.py`
4. Open `http://127.0.0.1:5000` in a browser.

The webpage sends the selected operation to the Python backend, and the result is shown on the page.
